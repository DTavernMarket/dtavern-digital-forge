## 🎯 Especificações Técnicas

### Formatos Aceitos
- **JPEG**: Para fotografias e imagens complexas
- **PNG**: Para imagens com transparência
- **SVG**: Para ícones e gráficos vetoriais
- **WebP**: Para melhor performance (opcional)

### Otimização
- **Compressão**: Otimizar para web
- **Tamanho**: Máximo 500KB por imagem
- **Qualidade**: 80-85% para JPEG

### Responsividade
- **Mobile**: 400px de largura
- **Tablet**: 600px de largura
- **Desktop**: 800px de largura

## 🔧 Como Adicionar Imagens

1. **Baixe** as imagens necessárias
2. **Otimize** para web (compressão e redimensionamento)
3. **Renomeie** conforme a estrutura acima
4. **Adicione** ao diretório `src/assets/images/`
5. **Teste** a aplicação para verificar se carregam corretamente
